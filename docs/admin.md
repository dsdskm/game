# 관리자 페이지

`apps/admin`(포트 3002)에는 AI, 계정 관리 탭이 있습니다. 관리자 페이지와 관리자 API는 비밀번호 로그인 및 HttpOnly 쿠키로 보호됩니다. 서버 내부 API는 별도의 공유 토큰으로 보호되며, 브라우저에는 해당 토큰이나 `OPENAI_API_KEY`를 전달하지 않습니다.

## 설정

`apps/admin/.env.local`에 `ADMIN_PASSWORD`(4자 이상), `ADMIN_SESSION_SECRET`(무작위 32자 이상), `ADMIN_INTERNAL_TOKEN`(무작위 32자 이상)을 설정합니다. 서버의 `apps/server/.env.local`에도 **동일한** `ADMIN_INTERNAL_TOKEN`을 설정합니다. 배포 시에는 두 앱에 같은 내부 토큰을 Secret Manager로 주입하고 관리자 페이지 접근을 네트워크 및 인증 정책으로 추가 제한하세요. 환경변수를 바꾸면 두 앱을 재시작하세요. 4자리 비밀번호는 추측하기 쉬우므로 운영 환경에서는 더 긴 비밀번호를 권장합니다.

AI 탭은 주제 생성 프롬프트 → 랜덤 주제 만들기 → 단어 생성 프롬프트 → 주제 입력 및 단어 만들기 순서입니다. 랜덤 주제 만들기는 서버가 저장된 주제 생성 프롬프트로 OpenAI에 요청해 결과를 주제 입력칸에 채웁니다. 단어 만들기는 입력된 주제로 단어를 생성하고 결과 또는 오류를 팝업에 보여줍니다. 두 프롬프트는 각각 별도로 SQLite에 저장되며, 처음 저장하기 전에는 빈 칸과 서버 기본 프롬프트를 사용합니다. 단어 프롬프트에는 `{{category}}`가 필요합니다. 편집한 문구는 저장 후 다음 요청부터 적용됩니다. 두 생성 작업 모두 OpenAI 비용이 발생하며 `OPENAI_API_KEY`가 없으면 실패합니다. 일반 게임의 랜덤 카테고리는 여전히 기존 동물·음식 선택 규칙을 사용합니다.

프롬프트는 Node.js 22 이상의 내장 SQLite를 사용하며 기본 DB 경로는 서버 작업 디렉터리 기준 `data/word-prompts.sqlite`입니다. `AI_WORD_PROMPT_DB_PATH`로 경로를 지정할 수 있습니다. DB 파일은 Git에서 제외되며 배포에 자동 포함되지 않습니다. 운영 환경에서는 서버에 영속 볼륨을 연결하고 DB를 백업하세요. 여러 서버 인스턴스에서는 동일 파일을 별도 머신에 복제하지 말고 공유 DB로 옮겨야 합니다. 기존 JSON 파일의 단어 프롬프트는 DB에 저장값이 없을 때만 게임의 대체값으로 사용됩니다.

계정 관리 탭은 서버 메모리의 활성 토스 로그인 계정 목록과 세션 수만 보여줍니다. 회원 데이터베이스가 아니며 서버를 재시작하면 목록이 초기화됩니다.
