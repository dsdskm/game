# 게임 준비

게임 화면에서 카테고리, 문제 수, 방식, 단어를 차례로 선택한 뒤 시작합니다.

- 카테고리: 랜덤(동물/음식) 또는 로그인 후 직접 입력(최대 20자). 직접 입력한 새로운 카테고리에서 AI 단어를 만들려면 서버의 `OPENAI_API_KEY`가 필요합니다.
- 문제 수: 20문제 또는 로그인 후 직접 입력(1~50문제).
- 방식: 공격(내가 AI의 단어 맞히기), 수비(AI가 내 단어 맞히기), 공격 & 수비(공격 종료 후 수비로 전환).
- 단어: 수비가 포함된 방식에서 공백 없는 5자 이하 단어를 입력합니다. 공격만 선택하면 AI가 비공개 단어를 고릅니다.

서버가 요청을 다시 검증하고, 단어는 서버 세션에만 저장합니다. AI 키가 있으면 서버에서 단어가 실제 명사이고 카테고리에 맞는지 AI로 확인합니다. 키가 없으면 동물·음식 정답 은행에 있는 단어/별칭만 통과합니다. 수비 시 AI는 공개된 대화 기록으로 추측하며, Mock AI는 정답 은행의 후보를 순서대로 추측합니다. 정답 은행 외 자유 단어는 AI 키가 필요합니다. 현재 세션은 서버 메모리에만 저장되므로 재시작하면 진행 중인 게임이 사라집니다.
